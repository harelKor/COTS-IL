# מדריך לספק הישראלי

כל הפעולות נמצאות תחת **ניהול** (`/admin`) באתר.

## שני הדפים הראשיים

- **כל ההזמנות** (`/admin`): כל הזמנות הקבוצות בדף אחד. למעלה תיבה צבעונית לכל סטטוס עם המספר שלו; לחיצה מסננת ולחיצה נוספת מבטלת. אפשר לחפש לפי מספר קבוצה או מספר הזמנה. הזמנות שמחכות לך מופיעות ראשונות, הוותיקה קודם. לחיצה על כרטיס פותחת אותו במקום, עם הפעולה של השלב שלו. הזמנות שהסתיימו (נמסרו, נדחו או בוטלו) נמצאות בחלק המקופל בתחתית. הסינון והכרטיס הפתוח נשמרים בכתובת, אז אפשר לרענן או לשתף קישור.
- **הזמנות ספקים** (`/admin/purchasing`): כל הפריטים שעוד צריך להזמין, מאוחדים לסל אחד לכל ספק. ליד כל פריט תגיות של ההזמנות שהוא משרת (למשל "1690 #57 ×2"), ולחיצה על תגית פותחת את ההזמנה. אפשר להוריד סימון מפריט או מהזמנה כדי להשאיר אותם מחוץ לאצווה הזאת. "פתיחת סל" פותח את הסל באתר הספק, ו"סמן כנשלחה" (עם מספר ההזמנה אצל הספק) מעדכן בבת אחת את כל ההזמנות שבאצווה. מתחת: הזמנות ספק שנשלחו, עם המשלוחים והקליטה.

הלשוניות למעלה: כל ההזמנות, הזמנות ספקים, מסירות, דוחות, קבוצות (אישור הרשמות וסנכרון הקטלוג), קטלוג.

## הסטטוסים

| סטטוס | מה זה אומר | מה עושים בכרטיס |
|---|---|---|
| מחכה לאישורך | קבוצה שלחה בקשה | בודקים מחיר וזמינות, משלוח והערות, ו"שליחת ההצעה לקבוצה". קבוצה חדשה מאשרים מאותו כרטיס. |
| מחכה לאישור קבוצה | ההצעה נשלחה | קישורי אישור (וואטסאפ או העתקה) לכל כתובת של הקבוצה. "לשנות פרטים ושליחה לאישור מחדש" יוצר גרסה חדשה. |
| אושרה, מחכה לשליחה | יש פריטים שעוד לא הוזמנו מהספק | לכל ספק: "סמן כנשלחה" עם מספר ההזמנה אצל הספק, או "הוספה להזמנת ספק". אם אותה הזמנת ספק משרתת גם הזמנות אחרות, הכרטיס אומר כמה. |
| נשלחה | כל הפריטים הוזמנו מהספק | משלוח ומעקב, וקליטה במחסן. |
| הגיעה למחסן | הכול התקבל והוקצה | "הפקת תעודת משלוח". |
| נשלחה לקבוצה | יש תעודת משלוח שעוד לא נמסרה | הדפסה ו"סימון כנמסר". |
| הסתיימה | הכול נמסר, או שההזמנה נדחתה או בוטלה | סיכום עם התאריך של כל שלב. |

הזמנה שהפריטים שלה בשלבים שונים מוצגת בשלב המוקדם ביותר, עם שורת התקדמות (למשל "3 מתוך 5 פריטים נשלחו לספק") ופירוט לפי ספק ("WCP נשלח, AndyMark ממתין"). בכרטיס הפתוח לכל פריט יש תג שלב משלו.

שום דבר לא נשמר בנפרד: הסטטוס מחושב מההזמנה, מהזמנות הספק, מהקליטות ומתעודות המשלוח.

## דוחות

**דוחות** מציג מכירות, רכש, עלויות יבוא וזמני טיפול, עם ייצוא ל-Excel. לחישוב רווח צריך למלא שער דולר, כי המקדם 1.6 אינו המרת מטבע. מע״מ שסומן כבר קיזוז לא נספר כעלות.

**דוח חוסרים** מציג מה עדיין לא נמסר לקבוצות ומה עדיין לא הגיע מהספקים.

## סנכרון הקטלוג

הקטלוג מתעדכן כל לילה. טבלת הסנכרון בדף הניהול מציגה מתי כל ספק התעדכן לאחרונה. אם סנכרון נכשל, הנתונים הקיימים נשארים, GitHub שולח דוא״ל לבעל המאגר, ואחרי שלושה ימים בלי עדכון האתר מציג "זמינות לא אומתה".

## גיבויים

GitHub Actions מגבה את מסד הנתונים כל לילה (זרימת העבודה "Database backup"), מוצפן, ושומר 30 יום. כדי שזה יעבוד צריך סוד בשם `BACKUP_PASSPHRASE` במאגר. **שמרו את הסיסמה גם מחוץ ל-GitHub: בלעדיה אי אפשר לשחזר.**

### שחזור

1. מורידים את הקובץ `backup.dump.gpg` מהריצה הרצויה בלשונית Actions.
2. מפענחים:

   ```bash
   gpg --output backup.dump --decrypt backup.dump.gpg
   ```

3. משחזרים לפרויקט Supabase **חדש ונקי**, אחרי `npx supabase db push`, עם מחרוזת החיבור של ה-Session pooler (פורט 5432):

   ```bash
   docker run --rm -i -v "$PWD:/b" postgres:17 pg_restore --data-only --disable-triggers --dbname "<SESSION_URL>" /b/backup.dump
   ```

מומלץ לתרגל שחזור פעם בחודש על פרויקט ריק.
